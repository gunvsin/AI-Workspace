Why Claude Code Has a Second Brain — And Why It Works

A cognitive OS for high-stakes decisions: bias detection, pre-mortems, decision journals, and the architecture that keeps reasoning honest.
By Antigravity AI Workspace — 2026-10-12 — 6 min read

Most second-brain setups fail not because the AI is weak, but because the vault's fundamentals are missing. The folder taxonomy, the linking rules, the metadata fields — these come before the agent.

The design here is different. It starts with structure first, then adds the reasoning layer. The result is not another notes app — it is a cognitive operating system that interrogates its own reasoning.

The three layers

Vault layer (local-first) — Obsidian-style numbered folders (00-daily, 10-raw, 20-notes, 30-projects, 97-topics, 98-assets, 99-templates), 4 metadata fields per note (type, parent, links, status), backlink retrieval via NoteRelation, and a maintained VAULT-INDEX.md.

Dashboard layer — live metrics with animated explainers, an ask box for AI reasoning, and an entity graph that maps people, budgets, blockers, and projects to each decision.

Cognitive layer — the production prompt enforces pre-mortems, bias detection (sunk cost, confirmation, recency, optimism), Cynefin classification, Socratic diagnostics, steering sliders, and a 60–90 day decision-journal post-mortem loop.

Why the framework works

The production cognitive prompt (system-prompts/production-cognitive-prompt.md) is not decoration — it is the engine. It enforces pre-mortem first (assume failure at 18 months, trace backward), audits all four cognitive biases with confidence percentages, applies Cynefin before any recommendation, runs Socratic diagnostics, and demands steering-slider calibration.

"Don't just log decisions — verify them. The reasoning layer is what separates a second brain from a notes folder." — from the benchmark study comparing 7 apps.

The gap this closes

Notion AI gives you database power. Obsidian gives you a vault. Mem gives you chat. None give you both a structured vault and a reasoning engine that checks its own biases before recommending.

The repo is open-source, self-hostable (Docker + Postgres + Ollama), and independent — projects don't share runtime code. The cognitive protocol is the product; the dashboard is just the interface.
